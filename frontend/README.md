# Frontend de Ágora

Aplicación web responsive creada con React, TypeScript y Vite. Esta entrega
corresponde a la Fase 1: fundamentos técnicos, navegación y sistema visual.

## Requisitos

- Node.js 24 LTS.
- npm 10 o superior.

## Ejecución

```bash
npm install
npm run dev
```

## Calidad

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

La arquitectura y las decisiones de esta fase se documentan en
[`../docs/frontend.md`](../docs/frontend.md).
